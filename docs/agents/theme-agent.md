# Theme Agent Rules

Themes define:

```txt
experiential identity
```

NOT orchestration.

---

## Theme Responsibilities

Themes own:

- atmosphere language
- visual tone
- color systems
- material systems
- gradients
- overlays
- typography identity
- semantic opacity
- environmental semantics

---

## Themes MUST NOT Own

Themes must NOT own:

- navigation orchestration
- scene orchestration
- presentation composition
- runtime behavior
- transition coordination
- browser state

---

## Theme Philosophy

Themes provide:

```txt
visual possibility space
```

Runtime determines:

- intensity
- pacing
- activation

Presentation determines:

- composition

---

## Theme System Rules

Themes should remain:

- semantic
- composable
- identity-focused
- orchestration-agnostic

Avoid:

- runtime logic inside themes
- hardcoded presentation behavior
- renderer-specific orchestration
- navigation coordination
- composition ownership

---

## Semantic Token Philosophy

Prefer:

```txt
semantic visual tokens
```

instead of:

```txt
hardcoded visual values
```

Example:

```ts
opacity.surface.subtle
```

instead of:

```ts
opacity: 0.12
```

---

## Theme Goal

Themes should evolve toward:

```txt
runtime-reactive experiential identity
```

while remaining:

```txt
behaviorally passive
```
