# Rendering System

## System Identity

The rendering system is architected as:

### experiential orchestration expression

Rendering consumes:

- runtime orchestration
- cadence systems
- scene modulation
- composition pacing
- experiential semantics

Rendering exists to express:

### authored cinematic composition

NOT:

### dynamic UI behavior

---

## Core Rendering Philosophy

Rendering should remain:

- declarative
- compositional
- layered
- runtime-aware
- orchestration-consumptive

Rendering should NOT:

- own orchestration
- generate runtime behavior
- contain adaptive logic
- duplicate experiential semantics

Rendering is:

### orchestration expression

NOT:

### orchestration authority

---

## Rendering Authority Chain

The intended flow is:

```txt
content
→ composition contracts
→ runtime orchestration
→ cadence resolution
→ scene modulation
→ presentation behavior
→ rendering
→ experiential output
```

Rendering consumes orchestration.

It should NOT create orchestration.

---

❌ Dynamic composition generation

### rendering inflation
