# Composition Reactivity Architecture - Complete System

## System Overview

```
RUNTIME ORCHESTRATION
│
├─ Profile Resolution
│  └─ immersive | editorial | minimal
│
├─ Composition Contract
│  ├─ density: tight | balanced | spacious
│  ├─ rhythm: editorial | cinematic | immersive
│  ├─ transition: soft | balanced | dramatic
│  └─ reactivity: ← NEW
│     ├─ pacing { revealGrouping, spacingModifier, staggerDistribution }
│     ├─ breathing { breathingFactor, pressure, groupingIntensity }
│     └─ density { effectiveDensity, pressureModifier }
│
└─ Motion Cadence ← CONSUMES REACTIVITY
   ├─ stagger ← influenced by staggerDistribution + revealTimeModifier
   ├─ sectionDelay ← influenced by breathingFactor
   ├─ transitionSoftness ← influenced by pressure
   └─ fade/reveal timing ← influenced by composition

PRESENTATION CONSUMPTION
│
├─ MotionCadenceProvider
│  ├─ Provides: MotionCadence (breathing-aware timing)
│  └─ Provides: CompositionReactivity (semantic influence)
│
├─ Animation Components
│  ├─ useMotionCadence() → base timing
│  ├─ useCompositionReactivity() → semantic influence
│  ├─ applyBreathingModulation() → breathing-aware timing
│  └─ calculatePressureStagger() → distribution
│
└─ Section Components
   ├─ useCompositionReactivity() → semantic influence
   └─ calculateCinematicSpacingModifier() → spacing influence

THEME APPLICATION
│
└─ Visual identity through CSS/Tailwind
   (unaffected by composition reactivity)
```

## Data Flow

### Orchestration Layer

```
content/projects.ts
  └─ ProjectPresentation { composition: { density, rhythm } }

runtime/presentation/composition/contract.ts
  └─ resolveCompositionContract(presentation, profile)
     ├─ Reads authored composition metadata
     ├─ Resolves profile (immersive/editorial/minimal)
     └─ Generates CompositionContract {
        density, densityClass, rhythm, rhythmProfile,
        transition, atmosphere, overlays, sceneIntensity,
        reactivity ← CompositionReactivityContext
     }

runtime/presentation/motion/cadence.ts
  └─ resolveCadence(contract)
     ├─ Reads rhythmProfile + transition
     ├─ Resolves CompositionMotionInfluence from reactivity
     └─ Applies influence to base timing values
        ├─ stagger *= staggerModifier * revealTimeModifier
        ├─ sectionDelay *= breathingDelayModifier
        ├─ transitionSoftness *= pressureSoftness
        └─ Returns MotionCadence (breathing-aware)
```

### Presentation Consumption Layer

```
ProjectPresentationRenderer
  └─ <MotionCadenceProvider contract={composition}>
     ├─ Provides: cadence via MotionCadenceContext
     ├─ Provides: reactivity via CompositionReactivityContext
     └─ children
        ├─ Animation Components
        │  ├─ useMotionCadence()
        │  ├─ useCompositionReactivity()
        │  └─ Optional: applyBreathingModulation()
        │
        └─ Section Components
           ├─ useCompositionReactivity()
           └─ Optional: calculateCinematicSpacingModifier()
```

## Reactivity Semantics

### Pacing Semantics

```
Determines: How reveals are grouped and distributed

Generated by: resolveCompositionPacing(profile)

Types:
- revealGrouping: tight | balanced | relaxed
- spacingModifier: 0.8-1.2
- staggerDistribution: compressed | natural | expanded

Influences: Reveal cadence and distribution tightness
Applied by: Cadence resolution through staggerModifier
Consumed by: Animation components via calculatePressureStagger()

Example (Immersive + Spacious):
- revealGrouping: relaxed
- spacingModifier: 1.15
- staggerDistribution: expanded
  → reveals distribute slowly, spacing opens up
```

### Breathing Semantics

```
Determines: Compositional pressure and spatial openness

Generated by: resolveCompositionBreathing(profile)

Types:
- breathingFactor: 0.85-1.2
- pressure: gentle | balanced | intense
- groupingIntensity: tight | natural | spacious

Influences: Section timing and compositional tension
Applied by: Cadence resolution through breathingDelayModifier + pressureSoftness
Consumed by: Animation utilities for delay/softness modulation

Example (Immersive):
- breathingFactor: 1.2
- pressure: gentle
- groupingIntensity: spacious
  → section delays lengthen, pressure softens, sections feel open
```

### Density Reactivity Semantics

```
Determines: Runtime-influenced compositional pressure

Generated by: resolveCompositionDensity(profile, sceneIntensity)

Types:
- effectiveDensity: tight | balanced | spacious
- influencesBreathing: boolean
- pressureModifier: 0.7-1.3

Influences: Overall compositional pressure through pressure modifier
Applied by: Cadence resolution through spacing influence calculation
Consumed by: Animation utilities for distance/spacing modulation

Example (Tight):
- effectiveDensity: tight
- pressureModifier: 1.2
- influencesBreathing: true
  → composition feels compressed, pressure intensifies
```

## Consumption Utilities

### Motion Influence Resolution

```ts
resolveCompositionMotionInfluence(contract)
  ├─ Extracts revealTimeModifier from reactivity
  ├─ Calculates staggerModifier from staggerDistribution
  ├─ Calculates breathingDelayModifier from breathingFactor
  ├─ Calculates pressureSoftness from pressure
  └─ Returns CompositionMotionInfluence
```

### Motion Application

```ts
applyCompositionMotionInfluence(baseStagger, baseSectionDelay, influence)
  ├─ stagger = baseStagger × staggerModifier × revealTimeModifier
  └─ sectionDelay = baseSectionDelay × breathingDelayModifier
```

### Animation Utilities

```ts
calculateBreathingDelay(baseDelay, reactivity)
  → baseDelay × breathingFactor × pressureModifier

calculatePressureStagger(baseStagger, reactivity)
  → baseStagger × groupingIntensityModifier

calculateBreathingDistance(baseDistance, reactivity)
  → baseDistance × pressureModifier

applyBreathingModulation(cadence, reactivity)
  → cadence with breathing applied to fade/reveal/stagger

calculateCinematicSpacingModifier(reactivity)
  → spacingInfluence clamped to 0.9-1.1

calculateCompositionalSeparation(reactivity)
  → "tight" | "natural" | "spacious"
```

## Architectural Guarantees

### 1. Runtime Semantic Ownership

✓ Runtime orchestration generates semantics only
✓ Presentation interprets and applies
✓ No reverse dependencies
✓ Clean separation of concerns

```
Runtime: WHAT should happen (orchestration)
Presentation: HOW it visually appears (interpretation)
```

### 2. No Layout Generation

✓ Utilities modify modifiers only (0.85-1.25 range)
✓ No dynamic class construction
✓ No flex/grid generation
✓ Authored composition structure preserved

### 3. No State Machine Orchestration

✓ All functions are pure and deterministic
✓ No stateful layers
✓ No complex orchestration dependencies
✓ Predictable, understandable behavior

### 4. Authored Composition Preservation

✓ Reactivity is optional consumption
✓ Graceful fallback to neutral values
✓ Modifiers clamped to safe ranges
✓ Breathing influence is subtle, not structural

## Integration Example: Full Flow

```tsx
// 1. ORCHESTRATION - resolves semantics
const composition = resolveCompositionContract(
  presentation,      // { density: "spacious", ... }
  profile,            // { immersive, density: "spacious", ... }
  profile.sceneIntensity // "balanced"
);
// Returns: CompositionContract {
//   density: "spacious",
//   reactivity: {
//     pacing: { ... },
//     breathing: { breathingFactor: 1.2, pressure: "gentle", ... },
//     density: { pressureModifier: 0.8, ... },
//     spacingInfluence: 1.15,
//     revealTimeModifier: 1.1
//   }
// }

// 2. MOTION RESOLUTION - applies reactivity to timing
const cadence = resolveCadence(composition);
// Returns: MotionCadence {
//   stagger: baseStagger × 1.05 × 1.1,  // ← influenced
//   sectionDelay: baseSectionDelay × 1.2,  // ← influenced
//   transitionSoftness: 1.2 × 1.05,  // ← influenced
//   ... other timing values
// }

// 3. CONTEXT PROVISION
<MotionCadenceProvider contract={composition}>
  <RevealAnimation />
</MotionCadenceProvider>

// 4. COMPONENT CONSUMPTION
export function RevealAnimation() {
  const cadence = useMotionCadence();
  const reactivity = useCompositionReactivity();
  
  // Optional: Apply breathing modulation
  const breathingCadence = applyBreathingModulation(cadence, reactivity);
  
  return (
    <motion.div
      initial={{ opacity: 0, y: 40 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{
        duration: breathingCadence.reveal.duration,  // ← breathing-aware
        delay: breathingCadence.fade.delay,           // ← breathing-aware
      }}
    />
  );
}
```
